# Student Management System

A simple web application to manage student records.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add student details
- Display student records
- Delete student records

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a student's name, roll number, and course.
4. Click the Add Student button to add a record.

## Project Purpose
This project is used to compare GitHub, GitLab, and Bitbucket by managing the same sample project on all three platforms.
